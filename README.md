# IAS Viewer — نسخه‌ی اندروید

**IAS Viewer — نسخه‌ی 2.0.80-beta (اندروید)**

نسخه‌ی مینیمال اندروید برنامه‌ی IAS Viewer؛ فقط دو صفحه:
- **🏠 صفحه‌ی اصلی:** پخش زنده‌ی دوربین‌ها (گرید؛ لمس هر دوربین = تمام‌صفحه)
- **⚙ تنظیمات:** مدیریت دوربین‌ها (افزودن/ویرایش/حذف) + تغییر رمز عبور

## ورود

در اولین اجرا دو کاربر به‌صورت خودکار ساخته می‌شوند (مشترک با نسخه‌های
ویندوز و مک):

| کاربر | رمز | دسترسی |
|---|---|---|
| `admin` | `Aa@@Sorena` | همه‌ی صفحه‌ها (تعویض رمز در اولین ورود اجباری است) |
| `Test` | `123456` | فقط صفحه‌ی اصلی و تنظیمات |

## نصب

1. از صفحه‌ی Actions آخرین بیلد سبز «Build Android APK» را باز کنید.
2. فایل `IAS-Viewer-ANDROID-vX.Y.Z.apk` را از بخش Artifacts دانلود کنید.
3. روی گوشی نصب کنید (نصب از منابع ناشناس را یک‌بار تأیید کنید).

## تعریف دوربین

وارد «تنظیمات» شوید ← «افزودن دوربین» ← نام + آدرس استریم
(مثلاً `rtsp://user:pass@192.168.1.10:554/stream1`).
